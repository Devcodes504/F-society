# F-SOCIETY

Herramientas:
- Escáner de red con nmap
- Generador de contraseñas seguras
- Obtener información de un numero

## 📲 Instalación en Termux:
```bash
pkg update && pkg upgrade -y
pkg install python nmap git -y
pip install python-nmap colorama
git clone https://github.com/Devcodes504/F-society.git
cd F-society && python F-SOCIETY.py
```
## 💻 Instalación en Linux:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip nmap git -y
pip3 install python-nmap colorama
git clone https://github.com/Devcodes504/F-society.git
cd F-society && python3 F-SOCIETY.py
```
